# Portfolio project direction

## Confirmed design brief

The user wants a complete visual rebuild from scratch: a new theme and design representing colorful Indian culture, with **festive, playful Indian pop art** and **3D art**.

The existing cinematic game/HUD appearance is not a design constraint. Create a new visual identity, composition, typography, color system, and presentation. Preserve verified personal/project facts, useful functionality, and technical infrastructure where appropriate.

Before portfolio design or implementation work, read `docs/indian-pop-art-rebuild-brief.md`. It records researched skills, cultural sources, possible art concepts, and engineering considerations. Proposed motifs and palette choices in that document are not confirmed user preferences.

External skills listed in the research have been studied, not installed. Consult relevant original references when needed and verify APIs against the project's installed versions. Current declared stack includes React 18, R3F 8, and Three.js 0.160; do not copy newer WebGPU/TSL or React 19 assumptions without a deliberate compatible migration.

The user authorized implementation on 2026-10-11. The new Indian pop-art website is implemented. Read `docs/design-system.md` for the delivered visual system and maintenance notes. Later explicit user directions take precedence over this recorded brief.
